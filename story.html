The problem

New Steel Structures was managing $20M+ in projects across five states. The tools were solid — accounting, spreadsheets for analysis, a project tracker. They just didn't talk to each other.

  • Triple data entry: bills keyed into accounting, the tracker, and the spreadsheet
  • Stale data: Tuesday's WIP report was already a week old
  • 25–30 hours a week spent assembling reports by hand

What was built

A unified operations system pulling directly from accounting as the single source of truth. Real-time visibility into WIP, cash flow, collections, and project health, synced automatically every morning.

What it became

That system — one source of truth, data flowing one direction, the screen never doing math — is the architecture the syncIO Operational Intelligence Platform runs on for every client today, regardless of industry.

The single-source-of-truth rule

Every calculation follows a strict five-layer path. Data flows one direction only: from the source system through the sync layer, stored raw in the database, calculated in the API layer, and displayed in the frontend. The first rule: the frontend never calculates. If the same number could exist in two places with two different values, the architecture failed. That separation eliminated reconciliation errors entirely — and it's still the first rule of the platform.
